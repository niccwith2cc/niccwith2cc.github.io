04 / control systems / 2022

A goalkeeper with a control loop.

A physical mechatronics project that connected sensing, prediction, and motor control to intercept a moving ball.

The brief

The rotating arm had to react to a moving ball fitted with an accelerometer. The challenge was to tune a controller that could make the arm respond reliably on real hardware.

The build

I designed and implemented the control system in MATLAB/Simulink and LabVIEW, tuned a PID controller for the DC motor, and deployed the system to a real-time microprocessor for integration and testing.

  • Connected sensor input to a real-time control loop.
  • Tuned PID behavior for a moving mechanical target.
  • Tested the controller through hardware integration rather than simulation alone.
RoleControl systems project
ToolsMATLAB, Simulink, LabVIEW

A model only matters when the hardware responds.
