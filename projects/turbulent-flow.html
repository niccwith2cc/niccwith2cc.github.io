Turbulent flow, stored smarter.

A parallel C++ simulation workflow that made large flow datasets cheaper to compute and easier to handle.

The challenge

Turbulent-flow simulations produce a lot of data. The project focused on making output more efficient without losing the information needed to inspect and understand the simulation.

The approach

Working in a team of four, I helped implement HDF5 output for a C++ turbulent-flow solver and parallelized the workflow with OpenMPI. The result was tested against the existing simulation setup and measured for both runtime and storage.

  • Designed an efficient large-data storage path for simulation output.
  • Used parallel execution to keep the workflow practical at larger scales.
  • Kept the output compatible with analysis and visualization workflows.
RoleScientific computing project
ToolsC++, OpenMPI, HDF5

The measured result

30% less runtime.
50% smaller files.
